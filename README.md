## Tech Stack and Configuration
- **Framework Vue and Vite**
- **External API:** Axios
- **Axios Configuration:** Axios is configured to use the base URL defined in the environment variables.
- **UI Components:** Vue components are used to create the user interface.
- **Styling:** CSS is used for styling the user interface.
- **State Management:** Pinia is used for state management.
